What this installer does

Installs to:

/opt/loombre/<version> — Node runtime, bundled ffmpeg and PostgreSQL, server + worker + web UI

/opt/loombre/current — symlink to the active version (upgrade swap point)

/Applications/Loombre.app — menu bar controller (status, start / stop / full shutdown, logs)

/Library/Application Support/Loombre — app data (config, embedded-PG data dir, local secrets)

/Library/Logs/Loombre — server / worker / web .out.log and .err.log files

/Library/LaunchDaemons/com.loombre.server.plist, com.loombre.worker.plist, com.loombre.web.plist — the three background services

/Library/LaunchAgents/com.loombre.menubar.plist — starts the menu bar app at login (and right after this install)

Creates a dedicated, unprivileged system account (_loombre) that the server, worker, and web UI run as — never root, never your login account.

After installation, the web UI is reachable at http://localhost:3000 (the API serves on port 3001). No database setup is required — the server provisions its bundled PostgreSQL automatically on first boot. To use your own PostgreSQL instead, or to reach the web UI from other devices on your network, see /Library/Application Support/Loombre/config/loombre.env and docs/install/macos.md for full configuration and first-run instructions.

Full layout rationale: installers/macos/LAYOUT.md in the Loombre source repository.
