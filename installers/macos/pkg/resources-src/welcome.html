Loombre — self-hosted media streaming

This installer sets up the Loombre media server, worker, and web UI as background system services (LaunchDaemons), running as a dedicated, unprivileged service account (_loombre). It bundles its own Node.js runtime, ffmpeg, and PostgreSQL — nothing else on your Mac is required or modified outside the paths listed in the accompanying README.

This build is UNSIGNED (Loombre does not pay for an Apple Developer ID — see docs/install/macos.md in the repository for exactly why, and for the checksum and signature verification steps that are the real trust mechanism for an unsigned open-source installer). Gatekeeper will show a warning the first time you try to open it; that is expected.
